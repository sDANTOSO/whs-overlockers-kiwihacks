# Space Fruit

A simple 2D platfromer built in Godot for Kiwi Hack Nova - Wellington.

Instructions:
- You need to get your spaceship to get home
- You're living off fruit
- Follow the arrows
- Jump on the platforms
- Avoid the alien bugs
- Controls are w-a-s-d and space to jump
